# ChatLincs
A multimodal RAG LLM project build for "NTT Data - Monitoring and Engagement Tracking for Impact Reports"

## Environment Setup

A `chatlincs.yml` file is provided to easily set up the project environment.

### 1. Create and Activate the Environment
```bash
conda env create -f chatlincs.yml
conda activate chatlincs
```

### 2. Verify the Installation
Check if the environment was set up correctly:
```bash
conda list
```
